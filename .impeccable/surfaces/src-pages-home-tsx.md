# Home surface brief

## Scope

Public home page (`/`). Visitor mode: Persuade. Build path: code-led (no image generation available).

## Audience, job, action

- Parents in Kathmandu choosing coding classes for a child aged 8 to 16, usually on a phone in the evening; secondary: teens and young adults, then schools and organisations.
- Job: understand what the child will learn and build, trust the class (size, mentor, place), and act.
- Action in working form: pick the child's age and interest, see the recommended path, book a free demo class (opens the existing advisor inquiry with the course pre-selected).

## Proof and constraints

- Real facts only: 6 courses and durations, 1:12 mentor ratio, in-person lab in Putalisadak, free demo / diagnostic session, fees quoted on inquiry, certificate on capstone. No photos, testimonials or numbers that do not exist; all previous AI/stock imagery is removed.
- Business logic, Supabase data, routing and SEO metadata unchanged.

## Direction contract

THESIS: The page is a program a child snaps together. It refuses the category default of a smiling-kids photo hero over a row of feature cards; the mechanism (blocks that become real code) is shown working, not described.

OWN-WORLD: Saturated block colour fields own whole regions on white: editor blue, event yellow, control orange, looks violet, operator green, ink #0F1640. Components are interlocking blocks with a top socket and bottom tab, bevelled edge, soft drop shadow; hat blocks start a script; Bricolage Grotesque display, Geist body, Geist Mono only for real code.

STORY: A parent sees the editor, taps their child's age, watches the path snap together from Scratch to Python, believes the progression and the small class, and books a free demo class.

FIRST VIEWPORT: Full-bleed editor-blue field. Headline across the top at display scale. Below it a three-pane editor at full width: block palette (age and interest chips) left, script area centre where the course path snaps in, stage right showing the project the child builds plus the orange "Book a free demo class" hat block as the primary action.

FORM: Snap Lab, assigned candidate 6 of 7 grounded directions; seed:9455829b2d419cf4. Raises: one idea per viewport; connections snap in sequence; state drawn on the block; curriculum notes on leader lines; one three-step depth scale.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Memorable moment

Choosing an age and watching the block stack rebuild itself, then flipping it to the same program written in Python.
